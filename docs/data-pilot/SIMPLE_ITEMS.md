# آیتم‌های ساده / مونتاژی (Simple / Lite Items)

> این آیتم‌ها از همان ستون‌فقرات «ماده غذایی بر اساس id» استفاده می‌کنند؛ بنابراین فیلتر آلرژی، محاسبه‌ی تغذیه و شخصی‌سازی دقیقاً مثل بقیه‌ی دستورها روی آن‌ها هم اعمال می‌شود.

- **مجموع آیتم‌های جدید (lite): ۹۶**

  - میان‌وعده (snack): ۲۴
  - نوشیدنی (drink): ۱۸
  - مخلفات / کنار غذا (side): ۱۳
