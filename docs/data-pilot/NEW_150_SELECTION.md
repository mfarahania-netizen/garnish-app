# انتخاب غذاهای جدید — بازبینی پیش از تألیف

<div dir="rtl">

این سند فهرست غذاهای پیشنهادی برای دور بعدی افزودن دستورها است (۱۸۱ غذا). پیش از شروع تألیف، لطفاً فهرست را مرور کنید و هر موردی را که می‌خواهید جایگزین یا حذف شود علامت بزنید.

**نسبت کلی:** ایرانی ۳۸ (۲۱٪) · بین‌المللی ۱۴۳ (۷۹٪).

**گستره آشپزی:** پوشش گسترده‌ای از فرهنگ‌های غذایی جهان — ایران، فرانسه، ایتالیا، آمریکا، ژاپن، چین، کره، هند، ویتنام، تایلند، مکزیک، اسپانیا، ترکیه، مراکش، مصر، آرژانتین، برزیل، پرو، و بسیاری دیگر.

> **یادداشت برای بنیان‌گذار:** پیش از آغاز تألیف دستورها، لطفاً جدول‌های زیر را مرور کنید و هر غذایی را که مایل به جایگزینی، حذف یا افزودن آن هستید مشخص کنید. این فهرست پایهٔ گام تألیف خودکار است.
