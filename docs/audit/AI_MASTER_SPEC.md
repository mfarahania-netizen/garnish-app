## THESIS (one paragraph)

Garnish does not need to "build AI from scratch." It needs to flip on a live model that already sits behind a fail-closed deterministic allergy gate, plug in a structured taste-graph moat that is **built-but-unused**, make the assistant **act** (not just answer) so every "apply" tap becomes both product value and the training signal three starved learning loops need, and layer a governed, audited admin-analytics agent on top of the honest analytics substrate that already exists — all on a no-rework layered path where each layer activates the next. The defensible asset is not the recipes; it is the **taste graph** (ingredient-level food intelligence × per-user learned taste × GRIS food-science) and the **cost flywheel** (every paid LLM call is a one-time tuition fee folded back into the free deterministic tier, so unit cost bends DOWN with usage while accuracy bends UP — the literal inverse of pure-LLM competitors). The architecture's single most defensible choice is that **the LLM narrates the deterministic answer; it is never the source of a fact, a quantity, or a safety decision** — which is simultaneously the cost moat, the no-hallucination moat, and the EU-"compliant-by-construction" moat.

# DIMENSION 1 — Capability & Conversational UX

**(A) SOTA bar.** NLU = fast deterministic router (RouteLLM-class) + a cross-lingual embedding tie-breaker (e5/LaBSE) for paraphrase and intra-utterance fa↔en code-switch (the hardest NLU/ASR case) — not language-detect-then-route. Memory = CoALA taxonomy (working/episodic/semantic/procedural) + multi-layer adaptive retrieval; window+rolling-summary is table-stakes, cross-session episodic recall is the differentiator. Voice = speech-to-speech realtime (Gemini Live) with semantic turn-detection + barge-in for noisy kitchens; code-switched Perso-Arabic ASR degrades commercial systems badly → Farsi quality MUST be validated empirically, not assumed. Multimodality = SOTA VLMs ~88% dish recognition / ~75% composition; calorie estimation stays unreliable → a photo is a discovery/assist aid, **never** a source of an allergen verdict or a nutrition number. Proactivity = acceptance-supervised intervention over an event stream; every act carries a one-line rationale; ignored interventions raise the future threshold; default to silence. Failure UX = uncertainty-based + verbalized abstention (an explicit "OK to say I-don't-know" avoids ~half of hallucinations); conformal abstention gives a tunable accuracy↔hallucination dial; conversational repair asks ONE clarifying question instead of guessing. Omnipresence = ambient assistants attach to the current object (long-press / "I'm stuck on this step") with a typed per-surface payload, and carry ONE thread across surfaces so the user never re-explains.

**(B) Garnish design.**
- **Three-stage understanding cascade** on the BUILT `IntentClassifier`: (1) deterministic classify (sub-ms, €0), (2) cheap typo/fuzzy layer (Damerau-Levenshtein + Double-Metaphone, €0), (3) **flag-OFF** local cross-lingual embedding tie-breaker (e5-small via transformers.js, ~10ms, €0) used ONLY on ambiguous **non-safety** turns. **INVARIANT:** a fuzzy/embedding match on a safety anchor only ADDS recall on the safe side and escalates to STRONG; it can **never downgrade** a safety turn.
- **Two-tier memory.** Short-term = 8 verbatim turns + a ~300-token rolling summary placed EARLY in the cacheable prefix, with the user turn LAST. Long-term = a structured, gate-readable PROFILE memory (`UserContextGraph` + `UserFact`), not free-text. CoALA map: episodic = `ChatMessage` by `conversationId`; semantic = the taste/skill profile; procedural = the deterministic engines. **HARD RULE: the LLM summary is UNTRUSTED for safety** — confirmed constraints live only in the structured profile (this is what closes the conversational-allergy hole, Dim 4).
- **Voice (cook-mode v1.5, sandbox-first, POST-v1 decision gate).** Push-to-talk + one wake-phrase as the DEFAULT (no always-listening: privacy/battery/GDPR); barge-in + semantic turn-detection for kitchen noise; every spoken tool-call surfaced as an auditable step (so speech-to-speech never hides the allergy gate); graceful degrade to the on-screen deterministic step on low ASR confidence. **Voice rides the SAME router/grounding/gate — a new I/O channel, not a second brain.**
- **Proactivity = the jaw-drop playbook + an intervention-control policy.** AROMA selective silence (intervene only at step boundaries, GRIS `commonMistakes` failure points, or allergy hard-stops) at **≤3–5/day**; a "because-you-did-X-in-Garnish" rationale + a one-tap "why am I seeing this / turn off" on every nudge; an acceptance-supervised penalty loop where an ignored nudge **raises** that trigger threshold; maturity-band gated so it never overclaims at cold-start.
- **Failure UX = a typed abstention ladder** (`{status, honestReason, bestAlternative}`) treated as a FIRST-CLASS success state: low-confidence/rejected generation → deterministic grounded reply; empty retrieval → hybrid+alias retrieval → nearest SAFE alternative; genuinely missing data → says so + points to what DOES exist; cost cap → degrade (never lock out); genuinely ambiguous → ask ONE clarifying question; out-of-domain/medical → polite refuse + redirect.
- **Omnipresence = a typed `AssistantContext` per surface** carrying `{route, recipeId, GRIS slice, focusedIngredientId, currentStepIndex, locale, reconciledAllergenSet}` + ambient affordances (long-press-an-ingredient, "I'm-stuck-on-the-step") instead of an AI tab, + ONE `conversationId` carried recipe→cook→shopping→plan.
- **Feedback = mostly IMPLICIT** (apply-swap/scale/cook-this/abandon as `UserEvents` — which also closes the ZERO-events L1 gap), explicit thumbs used sparingly, + the keystone `AiTurnDecision` row (`requestId, intent, matched anchors, answeredBy, outcome`) so a thumbs-down joins back to the exact decision (the Loop-3 training set; Dim 3).
- **Multimodality (post-v1, honest framing):** a photo is an INPUT to discovery/technique help only; never the source of an allergen verdict or a nutrition number (those stay deterministic + an always-verify-labels hedge). Frame to investors as a learning curve with a stated error budget, not a day-1 capability.

# DIMENSION 2 — Knowledge, Grounding & Data

**(A) SOTA bar.** Retrieval = hybrid by default (2025-26 consensus): sparse BM25/lexical + dense vectors fused via Reciprocal Rank Fusion (RRF), then a cross-encoder reranker on top-K. Measured lift is real and large (two-stage hybrid+rerank Recall@5 ~0.816 vs ~0.644 BM25 / ~0.587 dense-only; MRR@3 ~0.43→0.61). RRF fuses on RANK not score (robust, no tuning). Plain keyword `contains` is **below even the BM25 floor** — not on the SOTA curve at all. [قطعی] **Small-corpus nuance:** at ~1,008 records vector RAG is NOT mandatory and is often the WRONG call — the 2025-26 "agentic search" consensus is to wrap the DB/API as allow-listed tools and query a deterministic slice, because a vector store has no notion of data-ownership/access-control/provenance (every chunk leaks to any agent with index access). **Garnish's allow-listed userId-scoped Prisma tools (NOT document/vector RAG) are genuinely SOTA-aligned and correctly reject pgvector at this scale; the gap is WITHIN-tool retrieval quality, not the architecture.** [قطعی] Grounding = "inferable ONLY from supplied evidence with span-level traceability"; ungrounded = hallucination (2025 taxonomy: Inaccurate, Over-Responsiveness, Excessive-Refusal, Overcitation, Improper-Citation). Faithfulness measured as a CI gate (RAGAS/FACTS-Grounding/QAFactEval span-level). **Critical 2025 finding: citation-PRESENCE metrics are gameable** — real grounding verifies the claim is ENTAILED by the cited span, not merely that a citation exists. Provenance = every factual claim carries a verifiable source pointer; learning-to-refuse (abstention) is a first-class trustworthiness behavior. KB = authoritative, source-locked, multilingual food/nutrition KB (USDA FDC ids, per-100g, cross-language alias graph) with a freshness/confidence tag per field — exactly what a Dutch-zero-Persian user needs (eggplant↔aubergine↔بادمجان).

**(B) Garnish design.**
- **KEEP the allow-listed deterministic-tools architecture** (NOT vector/document RAG) — SOTA-correct at this scale AND the only design where per-user data ownership is enforced in CODE (the `UserScopedTool where:{userId}` seam closes OWASP LLM01 structurally). Do not let an advisor talk you into pgvector at 1,008 records. [قطعی]
- **REPLACE keyword `contains` with HYBRID-WITHIN-TOOL:** structured-field match (ingredient/technique/dishType/region/diet) + curated cross-lingual alias expansion (fa/nl/en) + Postgres `tsvector` (BM25-class) + `pg_trgm` fuzzy, fused by RRF. Single highest-leverage retrieval fix and the largest reducer of FORCED LLM escalation (today a synonym miss is a silent dead-end pushing the turn to a paid model). Target Recall@5 ≥0.80 (vs the doc's ~0.64 estimate). **No new infra — Postgres ships `tsvector`+`pg_trgm`.** [قطعی]
- **GROUNDED-ONLY enforced OUTSIDE the LLM by an output VALIDATOR** (promote `eval/output-safety/output-safety-evaluator.ts` to the RUNTIME validator, not just the eval harness): reject any reply that names an entity-id not returned by a tool THIS turn, contains a computed quantity the deterministic layer did not produce, or is empty → degrade to the deterministic reply, never surface. **The LLM NARRATES the deterministic answer; it is never the source of a fact, quantity, or safety decision.** [قطعی]
